
# IBL Data Analysis

## Key publications:

### IBL brain-wide map

*A brain-wide map of neural activity during complex behaviour*\
https://www.nature.com/articles/s41586-025-09235-0

The main brain-wide-map paper associated with the dataset used in this course. The dataset contains hundreds of Neuropixels probe insertions across many mice, laboratories and brain regions.

### Standardised behavioural task

*Standardized and reproducible measurement of decision-making in mice*\
https://elifesciences.org/articles/63711

Describes the standardised behavioural paradigm used across the IBL collaboration.

### IBL data architecture

*A modular architecture for organizing, processing and sharing neurophysiology data*\
https://www.nature.com/articles/s41592-022-01742-6

Overview of the architecture underlying IBL's approach to storing, organising, processing and sharing multi-laboratory neuroscience data.
